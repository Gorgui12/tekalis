ARTICLE 2 — Informatique & Bureautique

« Je prends un Core i5 ou un Core i7 ? » Cette question revient souvent lorsqu'on cherche un ordinateur portable. Pourtant, choisir un PC uniquement en fonction du nom du processeur peut conduire à une mauvaise décision.

Un étudiant en gestion, un développeur, un comptable et un graphiste n'ont pas nécessairement besoin de la même configuration. Au Sénégal, où l'achat d'un ordinateur représente souvent un investissement important, il vaut mieux choisir une machine adaptée à son utilisation plutôt que de payer pour une puissance inutile.

Core i3, i5 et i7 : que signifient réellement ces noms ?

De manière générale, les gammes Core indiquent différents niveaux de performances au sein d'une génération donnée.

  • Core i3 : adapté aux tâches courantes et à une utilisation bureautique légère à modérée.
  • Core i5 : excellent compromis pour les études, la bureautique avancée, le développement et de nombreux usages professionnels.
  • Core i7 : destiné aux utilisateurs ayant besoin de davantage de puissance pour des tâches plus exigeantes.

Attention : un Core i5 récent peut être plus performant qu'un ancien Core i7. La génération du processeur est donc essentielle.

Pour un étudiant : inutile de surpayer

Pour Word, Excel, PowerPoint, navigation web, visioconférences, PDF et plateformes universitaires, une configuration équilibrée suffit généralement.

Nous recommandons de privilégier :

  • 8 Go de RAM minimum pour une utilisation confortable ;
  • 16 Go si vous utilisez beaucoup d'applications simultanément ;
  • un SSD pour démarrer rapidement Windows et les logiciels ;
  • un processeur récent et suffisamment performant pour votre usage.

Pour un étudiant en économie, gestion ou comptabilité

Excel peut devenir beaucoup plus exigeant lorsque les fichiers contiennent de nombreuses feuilles, formules, tableaux croisés dynamiques ou données.

Une configuration équilibrée avec un processeur de milieu de gamme, 16 Go de RAM et un SSD constitue souvent un excellent investissement pour les études et les premières années professionnelles.

Pour un développeur

Le développement web peut sembler léger, mais l'environnement de travail évolue rapidement : VS Code, navigateur avec plusieurs onglets, terminal, serveur local, Git, Docker, bases de données et parfois plusieurs projets ouverts simultanément.

Pour un développeur, 16 Go de RAM constituent une cible beaucoup plus intéressante que de simplement chercher le plus gros processeur possible.

Pour le graphisme et la vidéo

Photoshop, Premiere Pro, After Effects, Blender et d'autres logiciels créatifs peuvent nécessiter davantage de ressources.

Dans ce cas, il faut regarder l'ensemble de la configuration :

  • processeur ;
  • RAM ;
  • carte graphique ;
  • SSD ;
  • écran ;
  • système de refroidissement.

Un Core i7 avec une configuration mal équilibrée n'est pas automatiquement meilleur qu'un PC bien conçu autour d'un Core i5 récent.

Le SSD : le composant que beaucoup sous-estiment

Passer d'un ancien disque dur mécanique à un SSD peut transformer l'expérience quotidienne d'un ordinateur.

Le démarrage de Windows, l'ouverture des applications et l'accès aux fichiers deviennent généralement beaucoup plus rapides.

Pour un PC moderne, le SSD doit être considéré comme un élément essentiel et non comme un simple bonus.

Le choix Tekalis selon votre profil

  • Bureautique et études : Core i3 récent ou équivalent + 8 Go RAM + SSD.
  • Études avancées / gestion / comptabilité : Core i5 récent + 16 Go RAM + SSD.
  • Développement web : Core i5 ou équivalent + 16 Go RAM + SSD.
  • Développement avancé / virtualisation : Core i7 ou équivalent + 16 à 32 Go RAM selon les besoins.
  • Graphisme et vidéo : processeur performant + 16 Go RAM minimum + GPU adapté.

Le conseil le plus important

Ne demandez pas simplement « i5 ou i7 ? ». Demandez plutôt :

« Quelle configuration répond à mes besoins pendant les 3 à 5 prochaines années ? »

C'est cette question qui permet de réaliser un achat réellement intelligent.
